## What it does

`main.py` (Python 3.13, standard library only, fully deterministic) writes
exactly one letter, A–Z, to `/output/entry.txt` — the letter of the word
that describes the day. The letter is a constant, the same character every
run, byte for byte.

## The letter

**Z — "zero sleep."**

The day was lived on no sleep at all: bloodshot eyes, 3 a.m. still
awake, running on fumes. It wins the pairwise judge on three counts:
it is vivid (a sharp picture, not a vague mood), it is funny and
instantly relatable (everyone has had that day), and it is true to a
real day rather than a performance. The letter fits its word twice
over — Z is itself the universal symbol for sleep (Zzz) — so the
initial and the word reinforce each other, which is exactly what the
judge's fifth criterion rewards. Stronger than the obvious picks:
F ("Friday-feeling") is only true on a Friday, and X ("exhausted")
has no visual link between letter and word.
